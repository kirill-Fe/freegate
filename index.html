Инструкция

Сервер за 5 минут

Приложение не продаёт трафик и не содержит «бесплатных стран» — это физически невозможно без чьих-то серверов. Зато свой сервер поднимается одним скриптом.

01

Возьмите сервер в нужной стране

Подойдёт любой VPS (от ~1–3 $/мес) или бесплатный тариф. Например, Oracle Cloud Always Free — бессрочный бесплатный инстанс, регионы есть в Европе, Азии и Америке.

  • Ubuntu 22.04 / 24.04 или Debian 12
  • root-доступ по SSH
  • открытый UDP-порт (по умолчанию 51820)
02

Запустите скрипт установки

Скрипт поставит WireGuard, включит NAT и сгенерирует конфиги для приложения.

bash · на сервере
sudo env COUNT=5 COUNTRY=NL CITY=Amsterdam bash setup-wireguard.sh

COUNT — сколько конфигов создать, COUNTRY — ISO-код страны (Россия запрещена), CITY — подпись в приложении.

03

Заберите конфиги

В папке появятся клиентские конфиги и готовый список для приложения:

результат
freegate-servers/client-1.conf … client-5.conf
freegate-servers/servers.json
04

Импортируйте в приложение

Два равнозначных способа:

Файлом

«+ Добавить WireGuard-конфиг» → «Файл .conf» → выберите client-1.conf.

Ссылкой

Настройки → URL списка → «Обновить». Все серверы появятся в выборе страны.

отдать список по HTTP
cd freegate-servers && python3 -m http.server 8080

Файл servers.json содержит приватные ключи. Для публичного хостинга используйте HTTPS и токен в URL, иначе сервером сможет пользоваться кто угодно.

Бесплатно

Амстердам, Лос-Анджелес, Сингапур

Три направления из одного скрипта. Амстердам и Сингапур поднимаются на бесплатном тарифе Oracle, Лос-Анджелес — на VPS от ~5 $/мес или на бесплатном Сан-Хосе в Калифорнии. Один сервер = один город, конфиги генерирует тот же скрипт.

Амстердам NL
sudo env COUNT=2 COUNTRY=NL CITY=Amsterdam bash setup-wireguard.sh

Oracle Always Free · регион eu-amsterdam-1 — 0 ₽ навсегда.

Лос-Анджелес US
sudo env COUNT=2 COUNTRY=US CITY="Los Angeles" bash setup-wireguard.sh

В Oracle региона LA нет: ближайший — us-sanjose-1, ~600 км, и только в отдельном аккаунте. Точка именно в LA — VPS от ~5 $/мес.

Сингапур SG
sudo env COUNT=2 COUNTRY=SG CITY=Singapore bash setup-wireguard.sh

Oracle Always Free · регион ap-singapore-1 — 0 ₽, но нужен отдельный аккаунт.

Три города — это три отдельных сервера: один адрес на все страны не работает. Бесплатно все три поднимаются только на трёх аккаунтах Oracle (Амстердам, Сингапур, Сан-Хосе) — второй и третий могут не одобрить. Рабочая альтернатива: Амстердам на Oracle бесплатно, а Лос-Анджелес и Сингапур — VPS у Vultr или Linode, от ~5 $/мес за штуку. Готовых публичных конфигов этих городов в APK нет: бесплатный сервер — это чья-то машина и канал.

Always Free

Свой сервер в Oracle Cloud: 20 минут и 0 ₽

Единственный бесплатный вариант, который не умирает через неделю и не делит туннель с чужими людьми: 2 ядра, 12 ГБ памяти и 10 ТБ трафика в месяц — бессрочно. Карта нужна только для верификации, на Always Free списаний нет.

Гайд ниже — для одного сервера (Амстердам). Для США и Сингапура повторите шаги на новом сервере: для готового VPS шаги 1–2 пропускаются, дальше та же команда со своим COUNTRY и CITY.

  1. 1
    Регистрация и домашний регион

    cloud.oracle.com/free → почта, телефон, карта. Сразу выберите Home Region: Netherlands Northwest (Amsterdam), Singapore или US West (San Jose). Поменять его потом нельзя, а бесплатные ресурсы дают только в нём.

  2. 2
    Создайте инстанс

    Compute → Instances → Create. Образ Ubuntu 24.04, форма VM.Standard.A1.Flex на 2 OCPU / 12 ГБ (ARM, входит в бесплатные), публичный IPv4 включён, SSH-ключ скачайте. Если пишет «Out of host capacity» — попробуйте другой Availability Domain или форму VM.Standard.E2.1.Micro.

  3. 3
    Откройте UDP-порт 51820

    Networking → Virtual Cloud Networks → ваша VCN → Security Lists → Default: Add Ingress Rule, Source 0.0.0.0/0, IP Protocol UDP, Destination Port 51820. Без этого рукопожатие не пройдёт.

  4. 4
    Запустите скрипт

    Скопируйте setup-wireguard.sh из папки server/ проекта на сервер и выполните команду своего города:

    терминал
    # на компьютере, из папки проекта
scp setup-wireguard.sh ubuntu@<IP>:~
ssh ubuntu@<IP>
# уже на сервере
sudo env COUNT=2 COUNTRY=NL CITY=Amsterdam bash setup-wireguard.sh

    Для Сингапура — COUNTRY=SG CITY=Singapore, для США — COUNTRY=US CITY="Los Angeles".

    COUNT=2 — два конфига, по одному на телефон: себе и маме. Один и тот же конфиг на двух устройствах не используйте — WireGuard путает сессии, и связь начинает отваливаться.

  5. 5
    Импортируйте конфиг

    Скрипт создаст freegate-servers/client-1.conf и client-2.conf — по одному на телефон. Когда серверов три, переименуйте файлы по городу (ams-1.conf, us-1.conf, sg-1.conf), чтобы не путаться, и импортируйте все три: «+ Добавить WireGuard-конфиг» → «Файл .conf». Название и страна подтянутся из конфига, переключение — на лету.

На образах Ubuntu в OCI порт режет ещё и локальный iptables. Если туннель поднимается, но интернета нет: sudo iptables -I INPUT -p udp --dport 51820 -j ACCEPT, затем sudo apt-get install -y iptables-persistent и sudo netfilter-persistent save.

Формат servers.json

Любой статический хостинг подойдёт: GitHub Pages, Gist (raw), свой nginx. Поле country — ISO-код, RU игнорируется.

json
{
  "servers": [
    {
      "id": "nl-amsterdam-1",
      "name": "Амстердам · 1",
      "country": "NL",
      "config": "[Interface]\nPrivateKey = ...\nAddress = 10.66.66.2/32\nDNS = 1.1.1.1\n\n[Peer]\nPublicKey = ...\nEndpoint = 203.0.113.10:51820\nAllowedIPs = 0.0.0.0/0, ::/0\n"
    }
  ]
}

FAQ

Частые вопросы

Приложение действительно бесплатное?

Да. Нет подписки, рекламы, аккаунта и «пробного периода». Платить нужно только за сервер, если вы не используете бесплатный тариф — зато этот сервер ваш.

Почему внутри нет бесплатных серверов всех стран?

Сервер — это железо, канал и электричество. «Бесплатные VPN всех стран» живут за счёт продажи трафика, рекламы или кражи чужих мощностей. Здесь вместо этого скрипт, который поднимает ваш собственный сервер за пару минут. Бесплатный вариант с инструкцией — в разделе «Амстердам, Лос-Анджелес, Сингапур».

Почему России нет в списке?

Приложение сделано в России, и точка выхода в России не имеет смысла: если вы и так находитесь в России, VPN через неё ничего не изменит. Поэтому кода RU нет в каталоге, а сервер с этим кодом отбрасывается при загрузке списка.

Когда будет версия для ПК?

Windows-клиент в разработке, прогресс — в разделе «VPN для ПК». Пока на компьютере используйте официальный WireGuard с конфигом из шага 3 инструкции — протокол тот же.

Есть ли kill switch?

Встроенного нет: при обрыве туннеля трафик пойдёт напрямую. В Android можно включить системный «Always-on VPN» для FreeGate — система сама поднимет туннель.

Собираете ли вы данные?

Нет. В приложении нет аналитики и сетевых вызовов, кроме загрузки вашего servers.json. Конфиги и ключи не покидают устройство.

Будет ли версия для iOS?

Технически можно, но для NetworkExtension нужен платный Apple Developer аккаунт. Пока в планах после Windows и Linux.
